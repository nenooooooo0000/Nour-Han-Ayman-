# Nour-Han-Ayman-# Portfolio Website

A modern personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Dark luxury design
- Responsive layout
- Hero section with typing effect
- Skills, projects, certificates, and contact sections
- Floating WhatsApp and Instagram buttons
- Clean developer-focused aesthetic

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — typing animation and footer year
- `README.md` — project overview
